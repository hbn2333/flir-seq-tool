## 实现结果

- Height analysis 使用 ROI 自身的上下热端、行中心高度及独立毫米比例；保持原整块统计。分区可关闭，完整高度分析与 CSV 仍可用。
- 规范顶部向下的行索引、float64 温度和及有效数存入临时 SQLite。一次高度扫描同时生成整块统计，行数据独立标记完成能力。
- Profile 显示当前帧的横向行均温；Zones 后台读取完整行表，以有效像素加权生成三段均温和有符号 A−B，有界预览保留极值、缺失及异常时间断点。
- 分界以 px/mm 显示和输入，保存高度比例。图像显示所选 ROI 的热端、正方向及分界；不足三行或空几何分区明确拒绝/停用。
- 完整高度 CSV 导出全部 ROI、帧和高度行；分区宽表导出全部启用分区 ROI。两者冻结设置、后台流式写入与回读校验，检查源/结果/目标快照后原子发布。
- selection v4 保存标定、方向、分区及已记录父来源链，严格迁移 v1/v2/v3。新子 SEQ 增加直接父偏移，CSV 与界面区分未知来源及最早已记录祖先。
- 原生子 SEQ 保留摘要确认，确认态变蓝，取消、输入变化、失败与任务启动后恢复默认角色。
- Open SEQ 在同一 Figure 内准备和提交新会话；未保存设置支持保存/放弃/取消。旧 UI 拆卸与数据销毁分开，构建/首绘失败可回退，最终关闭回收当前会话。
