# FLIR SEQ 阶段 C1 时间范围设计

## 1. 目标

在现有只读温度帧查看器上增加商用热像分析软件式的时间范围选择流程。用户先在完整或当前工作区间内选择候选起止帧，再确认该范围，使查看器时间轴缩放到所选区间。用户可以重复缩小范围，也可以一次恢复完整原始序列。

本阶段只实现内存中的时间范围选择，不保存 `selection.json`，不执行旋转裁剪、测温点、矩形 ROI 或 MP4 导出。

## 2. 数据与只读约束

- 唯一有效工作目录为 `D:\carbonfoam\infrared`。
- 原始 SEQ 位于 `D:\carbonfoam\infrared\raw`，只允许通过 FLIR Science File SDK 读取。
- 不覆盖、不改写、不重命名原始 SEQ，不写回元数据。
- 温度帧继续按需读取，最多保留现有的小型 LRU 缓存，不加载完整温度序列。
- 区间持续时间只读取当前工作区间首末帧时间戳，不要求扫描所有温度矩阵。

## 3. 坐标与时间定义

查看器同时维护原始帧坐标和局部帧坐标。

- 原始帧号 `source_frame`：SEQ 内永久不变的零基帧号。
- 当前工作区间：原始帧闭区间 `[source_start, source_end]`。
- 局部帧号 `local_frame`：当前工作区间内从零开始的界面编号。
- 局部帧数：

$$N = source\_end - source\_start + 1$$

- 局部帧到原始帧的映射：

$$source\_frame = source\_start + local\_frame$$

- 原始帧到局部帧的映射仅在原始帧位于当前工作区间时有效：

$$local\_frame = source\_frame - source\_start$$

- 候选选择为局部帧闭区间 `[pending_start, pending_end]`，允许两端相等。
- 当前工作区间持续时间使用首末帧真实时间戳计算：

$$duration = t(source\_end) - t(source\_start)$$

单帧区间持续时间为 `0 s`。显示值以秒为单位，内部保留 `datetime` 差值精度。

## 4. 状态模型

新增独立的时间轴状态模型，负责纯状态与坐标映射，不依赖 Matplotlib。

状态至少包含：

- `source_num_frames`：原始文件总帧数。
- `source_start`、`source_end`：当前工作区间的原始闭区间。
- `current_local_frame`：当前显示的局部帧。
- `pending_start`、`pending_end`：待确认的局部闭区间。

状态模型提供以下操作：

- 局部帧与原始帧双向映射。
- 修改当前局部帧。
- 修改候选起点或终点。
- 确认候选范围。
- 恢复完整原始序列。

确认候选范围时，新的原始区间为：

$$new\_source\_start = source\_start + pending\_start$$

$$new\_source\_end = source\_start + pending\_end$$

确认后执行以下重置：

- `current_local_frame = 0`。
- `pending_start = 0`。
- `pending_end = N_{new}-1`。

允许在新工作区间内再次确认更小的候选范围。恢复操作不逐级撤销，始终一次恢复 `[0, source_num_frames-1]`。

## 5. 界面结构

现有 Matplotlib 查看器底部扩展为以下控件：

1. `Current frame` 单值滑块。
2. `Selected range` 双端范围滑块。
3. `Start frame` 和 `End frame` 两个局部帧号输入框。
4. `Confirm range` 按钮。
5. `Reset full sequence` 按钮。
6. 状态与错误信息区域。

确认范围后，两条滑块和两个输入框全部重新编号为 `0` 至 `N-1`。原始帧号不用于底部控件输入，而在图像上方或状态区单独显示。

状态信息至少显示：

- 当前局部帧号与局部总帧数。
- 当前原始帧号与原始总帧数。
- 当前帧绝对时间。
- 当前帧相对当前工作区间起点的时间。
- 当前工作区间原始起止帧。
- 当前工作区间帧数和真实持续时间，单位为秒。

## 6. 交互规则

### 6.1 当前帧滑块

- 拖动 `Current frame` 时显示对应局部帧。
- 只修改当前显示帧，不修改候选范围。
- 当前帧可以位于候选范围之外，但必须位于当前工作区间内。

### 6.2 候选范围滑块

- 拖动左端点时，更新候选起点并显示该起点帧。
- 拖动右端点时，更新候选终点并显示该终点帧。
- 当前帧滑块同步到正在调整的端点。
- 若一次事件中无法可靠判断活动端点，则比较事件前后的两个端点；只有一个端点变化时显示该端点，两个端点同时变化时显示候选起点。

### 6.3 帧号输入框

- 只接受十进制整数局部帧号。
- 按 Enter 后提交。
- 修改起点输入框时显示新起点帧；修改终点输入框时显示新终点帧。
- 输入框、范围滑块和当前帧滑块同步更新。

### 6.4 确认与恢复

- `Confirm range` 将候选范围转换为新的工作区间。
- 确认后显示新区间局部第 `0` 帧。
- 候选范围重置为新区间全长。
- 若候选范围已经等于当前工作区间全长，确认操作保持状态不变。
- `Reset full sequence` 一次恢复完整原始序列，显示局部第 `0` 帧，并将候选范围重置为完整范围。
- 所有程序化控件同步使用更新保护，避免 Matplotlib 回调递归。

## 7. 错误处理

以下输入被拒绝，且不得破坏原状态：

- 空字符串或非整数文本。
- 小于 `0` 或大于当前局部最大帧号。
- 新起点大于当前候选终点。
- 新终点小于当前候选起点。
- 尝试构造空工作区间。

错误显示在窗口内的状态区域，不依赖终端。下一次成功操作清除错误信息。输入错误后，输入框恢复为当前有效值。

读取帧或时间戳失败时保留现有 FileSDK 异常语义，不假装确认成功。

## 8. 组件边界

- `timeline.py`：纯状态模型、范围验证和坐标映射。
- `viewer.py`：Matplotlib 控件创建、事件联动、帧读取和状态文本刷新。
- `reader.py`：继续只负责原始帧与时间戳读取，不感知局部帧坐标。
- `cli.py`：本阶段不增加新的命令参数；`view` 自动获得时间范围控件。

这种边界保证后续 `selection.json` 保存原始帧范围时不依赖 Matplotlib，也为旋转裁剪和 ROI 坐标系统保留清晰接口。

## 9. 验证

### 9.1 单元测试

- 初始状态覆盖完整序列。
- 局部帧与原始帧映射正确。
- 候选范围端点验证正确。
- 首次确认后原始范围、局部编号和当前帧正确。
- 重复确认可继续缩小范围。
- 恢复操作一次回到完整序列。
- 单帧区间有效。
- 非整数、越界和反向区间不改变有效状态。
- 当前帧滑块、范围滑块、输入框和按钮联动正确。
- 程序化同步不会递归触发错误更新。
- 控件对象在 Qt 事件循环期间保持强引用。

### 9.2 真实 SEQ 集成测试

使用 `raw\Rec-000366-240_09_26_37_152.seq`：

- 从 65 帧完整范围选择并确认子区间。
- 验证局部第 `0` 帧映射到所选原始起点。
- 验证区间持续时间等于端点真实时间戳差。
- 验证重复缩小和完整恢复。
- 验证操作前后原始文件大小和纳秒级修改时间不变。

## 10. 完成判据

- 用户可通过范围滑块或帧号输入框准确选择候选范围。
- 拖动或输入任一端点时画面自动显示对应帧。
- 确认后两条滑块使用新区间局部编号，画面显示局部第 `0` 帧。
- 界面同时显示局部帧、原始帧和以秒为单位的真实区间长度。
- 可重复缩小范围，并可一次恢复完整原始序列。
- 全部自动测试通过，真实 SEQ 保持只读不变。
