# 子 SEQ 导出另存为设计

## 目标与范围

将 Process 页的子 SEQ 导出改为原生“另存为”对话框，移除 Clip name 输入框。用户已确认此交互方向。本次不改变帧提取、温度数据、旋转裁剪算法或 Measure 导出。

工作目录为 `D:\carbonfoam\infrared`，`raw` 下的原始数据始终只读。

## 交互

1. 点击 Export sub-SEQ，弹出原生另存为对话框。默认目录为 clips，建议文件名为源文件主名加导出范围，用户可修改目录和文件名。
2. 未提供扩展名时补充 .seq；已有 .seq 扩展名不重复添加，不区分大小写。拒绝空名称和不支持的扩展名。
3. 选择后检查路径与空间，显示导出帧范围、持续时间、SEQ 完整路径、同名 .selection.json 完整路径及各自是否覆盖。此时尚不写文件。
4. 按钮改为 Confirm export，第二次点击确认当前摘要，不再次打开对话框。
5. 确认前帧范围或导出配置改变，旧确认失效；下次点击重新选择目标并生成摘要。确认后目标被外部修改时，不静默覆盖，要求重新确认。
6. 对话框取消时不创建文件、不启动线程、不改变选择或变换。对话框错误显示可理解的信息，恢复控件可用状态。
7. 任务启动后继续使用现有后台进度、取消和成对发布流程；完成、失败或取消后恢复 Export sub-SEQ。

不新增“选择目录”按钮，不记忆跨会话目录，不在本次引入设置文件。移除 Clip name 后适当调整原有导出按钮位置，避免留下孤立标签。

## 文件与安全

选定 example.seq 后，配置文件固定为同目录 example.selection.json。SEQ 仍为官方 SDK 提取的原始帧；旋转裁剪保存在配置文件中，不重采样写入 SEQ。

保留源文件保护、raw 路径保护、路径别名检查、SEQ 与配置文件的目标快照、临时验证、成对发布与未完成发布恢复保护。导出目录可以改变，但不能以绕过保护为代价放宽校验。

目标在预览后发生变化时必须重新展示覆盖情况；不可在最终提交前刷新快照并默认用户已同意新目标。原始文件及既有实验导出结果不用于覆盖测试。

## 实现边界

- selection_dialogs.py：增加 SEQ 另存为适配及路径规范化，沿用原生对话框生命周期。
- viewer.py：保存待确认目标路径，修改两阶段导出回调，移除 Clip name 控件及其事件和状态切换。
- viewer_layout.py：调整导出行布局。
- extraction.py / export_bundle.py：复用现有导出和安全机制；所选目标的父目录作为此次输出目录，不固定为工作区 clips。
- 对应单元测试和 README：同步用户操作及控件契约。

## 验证标准

测试覆盖默认建议名称、任意合法目录、扩展名、取消与异常、摘要后确认不重复弹窗、输入改变导致确认失效、覆盖提示、外部目标变动、源文件/raw/别名保护、成对路径一致，以及隐藏控件鼠标抓取回归。

用最小真实 SEQ 导出少量帧到独立测试目录，验证帧数量、同目录配置和重新加载。记录源文件大小与 mtime，前后必须一致。执行相关单元测试及完整回归；大文件不作自动全量测试。
