## 1. 目标与范围

本轮同时完成三个相关工作：

1. 在已有矩形 ROI 与整块统计基础上提供逐帧、逐行的高度温度数据 $T(z,t)$；CSV 是主要数据产品，图形用于预览和检查。
2. 保留原生子 SEQ 导出的摘要确认，将确认态明确显示为蓝色主按钮。
3. 在同一软件窗口打开其他 SEQ，安全处理未保存设置、后台任务及资源释放。

现有 Process、整块 ROI 统计、直方图、横纵像素剖面、整块帧曲线及原生/视频导出继续保留。本轮不增加自动跟踪、自动找热端、透视矫正、热电偶对齐、实验加热起点、导热系数拟合或跨文件同步分析。当前文件中的各 ROI 使用共同时间基准。

## 2. 已确认的选择

| 问题 | 采用方案 | 取舍 |
| --- | --- | --- |
| 毫米标定 | 输入当前 ROI 覆盖的实际高度 | 全部操作依托 ROI，步骤少；输入长度必须对应矩形覆盖的范围 |
| 两点标尺 | 本轮不采用 | 可独立于 ROI 标定，但增加操作，用户选择 ROI 标定 |
| 高度分区 | 每个 ROI 一个“启用高度分区（低／中／高）”复选框 | 默认关闭；不阻止完整高度分析与 CSV 导出 |
| CSV 与图形 | 明确的全量高度 CSV 和分区 CSV 入口 | 不依赖当前图形子视图或绘图抽稀结果 |
| 子 SEQ 额外确认 | 保留摘要，确认按钮变蓝 | 保留帧范围、配套 JSON 和覆盖状态的复核机会 |
| 切换文件 | 保留主窗口，准备成功后切换会话 | 需要集中管理 reader、UI、回调与结果存储 |

沿用用户的文字设计偏好，不需要浏览器原型。

## 3. ROI、坐标与毫米标定

### 3.1 唯一空间定义

ROI 仍保存已 Apply 的旋转裁剪图像坐标：整数 `x、y、width、height`，对应数组切片 `values[y:y+height, x:x+width]`。所有高度数据直接由该变换后的摄氏温度矩阵计算；不从热图颜色反推，也不再次旋转插值。

设 ROI 高度为 $H$，数组行索引 $r=0,\ldots,H-1$，从图像上方向下增加。`heated_edge` 可选 `bottom` 或 `top`。热端由用户指定，不做图像自动识别。

- 下端受热：$k=H-1-r$，高度正方向向上。
- 上端受热：$k=r$，高度正方向向下。
- 零点为 ROI 靠受热端的外边界，每行均温定位在行中心，$z_{px}=k+0.5$，ROI 高度范围为 $[0,H]$。

保存规范的数组行索引 $r$，显示与导出另给高度坐标 $z$；反转高度方向不改变底层数据行的身份。图像上显示热端和正方向箭头。高／中／低表示 $z$ 的高低，低区靠近 $z=0$，与温度高低无关。

### 3.2 标定

默认未标定，使用像素单位。输入当前 ROI 覆盖的实际高度 $L>0$ mm 后：

$$p=L/H,\qquad z_{mm}=p\,z_{px}.$$

每个 ROI 有独立的 $p$，不假设不同样品或位置具有相同毫米比例。输入必须为有限正数；未标定时 CSV 的毫米字段留空。

例如 $H=100$、$L=10$ mm，则 $p=0.1$ mm/px，数据位置为 0.05、0.15…9.95 mm。

保存权威比例 `mm_per_pixel` 与本次标定参考值 `reference_height_px`、`reference_height_mm`，加载时核验三者一致。平移 ROI 或改变宽度保持比例；改变高度为 $H'$ 时保持 $p$，界面高度更新为 $pH'$，可以重新输入长度标定。纯单位切换不改变比例或数据。

同一 ROI、方向及比例用于整个已确认帧范围。Apply 不同图像变换继续沿用现有的确认清除 ROI 规则，相应标定与分区设置一并清除；不能把旧坐标的标定默默转移到新变换。

## 4. 逐行温度与三分区计算

### 4.1 完整高度剖面

逐帧读取温度矩阵，每帧变换一次，供全部 ROI 共用。对 ROI 某行的有限值集合 $V_r(t)$，保存有效数 $n_r(t)$、float64 温度和 $S_r(t)$，并计算：

$$T(z_r,t)=S_r(t)/n_r(t).$$

NaN 和正负 Inf 都无效。不做平滑、补值、温度阈值排除或时间插值。整行无效时保留该行，`valid_pixels=0`、温度为缺失；只有一个有效像素时均温即该像素温度。CSV 不按图形显示位数截断。

### 4.2 分区复选框

每个 ROI 的“启用高度分区（低／中／高）”默认不勾选。

- 未勾选：仍能看当前时刻 $T(z)$、计算完整 $T(z,t)$ 并导出完整高度 CSV；分区设置折叠。
- 勾选：展开低／中／高名称、两条分界位置和温差区间 A/B 选择；图像同步显示分界位置。
- 默认三等分，允许调整两条分界和名称。本轮采用三个连续分区，不另增加任意数量区间编辑器。

两条分界以 ROI 高度比例 $0<q_1<q_2<1$ 保存，默认 $1/3、2/3$；显示位置为 $q_iH$ px，已标定时允许输入毫米并转换为相同比例。低区为 $[0,q_1H)$，中区为 $[q_1H,q_2H)$，高区为 $[q_2H,H]$，按行中心 $z_{px}$ 判断归属。因此不重复计行，每行只归属一个区间。

启用时每区至少包含一个几何行。$H<3$ 时不能启用分区，但完整高度分析可用。非法分界输入保留最后有效设置并提示，不产生空几何分区。未启用时仍可保存合法有序的分界比例，不要求当前高度已经能容纳三个非空区间。

ROI 高度变化后保留分界比例，显示其新的像素/毫米位置；若高度或方向修改后某区不含几何行，则保留比例但关闭分区并明确提示，用户调整到有效分界后才能重新启用，不静默移动分界。更改毫米比例时只改变单位数值，区间覆盖的像素行不变。几何改变后的完整结果仍需重算。

### 4.3 分区均温与两种温差

某分区 $B$ 的均温为：

$$\overline T_B(t)=\frac{\sum_{r\in B}S_r(t)}{\sum_{r\in B}n_r(t)}.$$

这是全部有效像素的均温，等价于按各行有效像素数加权，不对各行均温简单等权平均。分区无有效像素时均温缺失。

区间 A、B 必须不同，默认低区减高区：

$$\Delta T_{A-B}(t)=\overline T_A(t)-\overline T_B(t).$$

保留符号；任一分区无有效数时温差缺失。现有 `max-min` 明确显示为“ROI 极差”，新量显示为“区间均温差 A−B”。旧 CSV 的 `delta_c` 不改语义；新分区 CSV 分别使用 `roi_range_c` 和 `zone_delta_c`。

## 5. 时间与帧号

所有 ROI 使用同一已 Confirm 范围，其首帧实际时间戳 $t_0$ 为共同起点：$t_i=(timestamp_i-t_0)$，单位秒。不按样品升温开始时间分别归零，不设置实验加热零点。

保留 SDK 的原始 ISO 时间表示，不给缺少时区的时间戳擅加时区。新增高度时间曲线使用实际秒数，不假设均匀帧率。原有整块统计视图的帧号横轴继续保留，CSV 的相对秒数定义一致。

时间戳重复或倒退时不重排或删帧，CSV 按源帧顺序保留真实时间。独立的 `time_status` 为 `ok`、`duplicate` 或 `backwards`，首帧为 `ok`，后续与前一源帧比较；图形在重复/倒退连接处断开并提示，仍保留对应数据点。相对秒数可能为负，不能裁成零。

任一时间戳缺失、无法解析或时区表示不兼容而无法计算相对时间时，整次计算失败并报告源帧号，包括首帧 $t_0$ 不可用的情况。温度读取失败同样整体失败，不能跳过失败帧后伪装成完整结果。

帧号严格区分：

- `local_frame`：当前已确认范围内从 0 开始的局部帧。
- `source_frame`：当前打开 SEQ 内的源帧索引；原文件名/身份同时导出。
- 来源映射：只有配套配置中有可核验记录时，另输出 `origin_source_identity_json`、`origin_frame`；固定指向该链最早已记录的祖先，`origin_scope=earliest_recorded_source`，`origin_depth` 为当前文件到该祖先的映射层数，`origin_status=recorded_chain`。只有一层时该祖先就是直接父文件。

没有记录的旧子 SEQ，来源身份/帧号留空，`origin_scope=unknown`、`origin_depth=0`、`origin_status=unknown`。直接打开某 SEQ 时，其 `source_frame` 总是可用，但不能仅凭文件名、路径或时间戳认定它就是最初录像。最早已记录来源也不能冒充已确认的最初录像；CSV 与界面明确标注来源范围。

新子 SEQ 的配置保存直接父文件身份、父文件选取起点、连续帧数，并保留已知父来源链。提取子文件第 $j$ 帧对应父文件 `parent_start+j`；已知链可逐层累计偏移。校验每一层范围、帧数及当前配套文件身份，不扫描或修改未知原文件来猜映射。

## 6. Measure 页面与导出入口

在当前结果视图切换中新增 `Height analysis`，与现有 Current frame / Frame curves 并列，共享 ROI 列表和当前帧滑块。

高度分析有两个结果子视图：

- **当前剖面**：横轴高度、纵轴 °C。使用当前帧滑块和帧号输入选择时刻；叠加勾选 ROI，颜色沿用 ROI，单位为统一选择的 px 或 mm。只有全部可见 ROI 都已标定时才启用 mm 比较；否则可切回 px，并显示哪些 ROI 未标定。
- **分区曲线**：上图为勾选且启用分区 ROI 的三条区间均温曲线，颜色区分 ROI、线型区分区间；下图为各 ROI 的 A−B。未启用分区的 ROI 仍有完整高度数据，但不出现在分区图。没有可用分区时显示勾选引导。

分区曲线图例同时含 ROI 与区间名称，不只依赖颜色。没有有效数据时显示空态；无效数据为断点，单帧/单行显示点。分区曲线可采用有界、保留极值和缺失断点的抽稀显示，必须标注抽稀；CSV 始终保留全部样本。

高度分析区域有明确的 `Calculate`、取消、进度和两个 CSV 入口：

1. `导出完整高度 CSV（全部 ROI）`：全部已创建 ROI、全部已确认帧、全部高度行；不受图形勾选、当前帧或分区开关影响。
2. `导出分区 CSV`：全部已启用分区的 ROI、全部已确认帧；无启用项时禁用。图形勾选仅控制显示，不删除导出数据。

完整高度 CSV 是首要操作，不能隐藏在分区模式内或复用“导出当前帧剖面”的模糊按钮。两个新入口与旧 Export CSV 语义分开；旧导出继续导出原分析子视图。

## 7. CSV 数据契约

### 7.1 通用要求

采用 UTF-8 BOM 和标准 CSV 转义；文本沿用现有公式注入防护。每个 CSV 自带追溯字段，不要求读取额外元数据文件才能解释坐标和时间。

通用字段包括：

- `format_version`、`algorithm_version`、`source_identity_json`、`transform_json`。
- `source_start`、`source_end`、`time_origin_timestamp`、`source_frame`、`local_frame`、`timestamp`、`relative_s`、`time_status`。
- `roi_id`、`roi_name`、`roi_x`、`roi_y`、`roi_width`、`roi_height`、`coordinate_space=cropped_pixel`。
- `heated_edge`、`height_direction`、`height_origin=heated_roi_edge`、`mm_per_pixel`、标定参考像素高度与毫米高度。
- `origin_source_identity_json`、`origin_frame`、`origin_scope`、`origin_depth`、`origin_status`；无法核实时不填造原始录像帧号。

数值量保留用于重现计算的浮点精度，不采用界面两位小数。未标定、全无效或无法追溯的字段为空，并以状态字段区分原因；空值不得替换为零温度。

### 7.2 完整高度 CSV

一行代表“一个 ROI × 一个源帧 × 一个高度行”，增加：

| 字段 | 定义 |
| --- | --- |
| `roi_row_index` | 从 ROI 顶部向下的规范数组行索引 $r$ |
| `cropped_y_pixel` | 裁剪图中对应行中心 `roi_y+r` |
| `height_pixel` | 从 ROI 热端外边界起算的行中心 $z_{px}$ |
| `height_mm` | 已标定时的 $z_{mm}$，否则空 |
| `row_mean_c` | 本行有限像素横向均温 |
| `valid_pixels`、`total_pixels` | 本行有限数及 ROI 宽度 |
| `status` | `ok`、`partial_invalid` 或 `no_finite_pixels` |

稳定排序为局部帧、ROI 创建顺序、高度从低到高。期望总数据行数为 $N\sum_j H_j$，包括全部无效行；不能因为图中不可见或无温度就省略。

### 7.3 分区 CSV

采用一行“一个启用分区的 ROI × 一个源帧”的宽表，方便后处理；低/中/高各有名称、分界比例、解析后的 px/mm 边界、均温、有效数、几何总像素数和状态。

同时输出 `delta_zone_a`、`delta_zone_b`、`zone_delta_c`、两端区间有效数及 `roi_range_c`。几何分区与方向/标定来自本次导出冻结快照，不能把改动后的边界套在旧的分区均温上。

### 7.4 流式与安全发布

CSV 导出使用独立后台任务，从只读结果表分批读取，不能在 GUI 主线程一次构建全部行或 DataFrame。显示预期行数、进度、取消；磁盘占用随 $N\sum H$ 增长，CSV 追溯字段重复也计入实际体积。

开始时冻结完整数据键和派生设置；导出期间禁止修改输入、切源或启动其他任务。写同目录临时文件，分块核验表头、数据行数及状态/数值约束，通过后再次核对源身份和目标快照，再原子替换目标。覆盖需原生确认，取消或失败保留旧文件并只清理本任务临时文件。仍保护当前源、别名和 raw 目录。

## 8. 结果存储、失效与资源

复用现有只读 reader、FrameTransformer 和 SQLite 临时结果的模式；不把全部温度矩阵或整张高度表装入内存。

普通整块统计 Calculate 保持现有轻量数据能力。高度 Calculate 一次逐帧扫描同时生成整块统计和全部 ROI 的逐行数据；高度结果可供整块曲线使用，只有整块统计的旧结果不能冒充完整高度结果。结果元数据明确标记统计能力、算法版本、各表期望行数与完成状态。

逐行表保存规范行索引、温度和、有效数及均温；公共时间信息可用帧表引用。唯一键为 `(roi_id, local_frame, roi_row_index)`。只有完成且与当前源、已确认范围、变换、全部 ROI ID/几何匹配的数据才可查询为有效全段结果。

基础数据键与派生设置键分离：

| 修改 | 原始逐行数据 | 需要的更新 |
| --- | --- | --- |
| 当前帧、页面、显示勾选、名字、颜色 | 保留 | 当前画面/描述 |
| 受热端、毫米标定、分区开关、边界、A/B | 保留 | 按规范行重新映射/聚合，无需重读 SEQ |
| 未 Confirm 的候选时间范围 | 保留 | 测量继续使用原已确认范围 |
| ROI 几何或已确认范围 | 失效 | 重算后才允许完整高度/分区 CSV |
| Apply 不同变换 | 清除 | 确认清除 ROI、标定、设置和结果 |
| 成功加载配置或切换源文件 | 清除 | 配置只恢复设置，结果重新计算 |

派生曲线按需从磁盘查询，使用后台任务或分块调度，不能因“无需重读 SEQ”就在主线程扫描几百万行。只有少量当前帧向量和有界绘图点进入内存。派生键包括方向、比例、区间和 A/B；旧派生结果不得当作新设置结果导出。

计算与导出复用现有任务互斥和源身份开始/结束核验。取消在帧或数据块边界检查，发布最后一步不被中断。失败/取消不标为完成，磁盘不足要报告；旧有效结果仅在输入键仍匹配时可恢复。

最终关闭会话必须停 timer、断开事件、结束任务、关闭 SQLite 和 reader，然后清理本任务拥有的临时目录。切源在提交前只拆卸 UI，数据资源在新会话提交后才销毁，具体顺序见第 11 节。便携版临时数据继续位于包内 cache，不能回落到系统临时目录。

## 9. 配置与来源兼容

selection 升到 schema v4，兼容读 v1/v2/v3。旧版本缺少高度设置时采用：下端受热、未标定、分区关闭、默认三等分及低−高温差对。v3 的原 ROI、视图和变换不得丢失。

高度设置按稳定 ROI ID 保存，包含受热端、由其确定的方向、标定、分区开关、两条边界比例、三个名称与 A/B；高度子视图设置亦保存。无效类型、非有限比例、重复 ID、越界分界或不存在的 ROI 引用必须明确拒绝，不能部分套用配置。

新增可选的来源链，与现有当前文件身份校验分开。新子 SEQ 将当前视图配置和高度设置带入同名 JSON，绑定子文件身份并记录连续父帧映射；父来源不完整时保留“未知最初录像”的状态。没有配套配置的 SEQ 仍可读取和分析。

Process 的 Save selection 仍保存候选范围，Measure 的 Save setup 保存已确认范围；高度设置和来源信息都加入未保存签名。保存不包含临时完整高度数据或帧曲线，加载后需 Calculate。沿用原子保存、单份备份及目标快照保护。

## 10. 原生子 SEQ 确认反馈

继续使用“Export sub-SEQ → 另存为 → 摘要 → Confirm export”。不取消现有第二次确认。

- 默认导出按钮为原角色；进入摘要确认态时文字变为“Confirm export / 确认导出”，角色切为 primary，立即刷新为与主操作一致的蓝色背景。
- 摘要明确 SEQ 与同名配置、路径、帧范围、覆盖状态；用户能看见正在等待再次点击。
- 开始导出、取消、确认失效或失败退回初态时，角色和文案一起恢复；忙状态不能保留可点击的蓝色确认按钮。
- 修改候选范围、配置或目标导致确认签名改变时仍需重新预检。路径/容量检查、覆盖提示、外部修改检测、原始数据保护、取消及两文件发布/恢复逻辑继续保留。

## 11. 同窗口打开其他 SEQ

### 11.1 交互

顶部公共导航增加 `Open SEQ / 打开文件`，Process 和 Measure 都可用。选择原生 `.seq` 文件，不复用加载 JSON 的选择框。

选文件取消或选到当前同一文件/别名时保持会话原样。有未保存更改时提供“保存后打开／放弃更改／取消”。

“保存后打开”采用窗口级保存入口，与当前所在页面无关，统一保存与 Process Save selection 相同的文档：候选范围作为下次加载的范围、已应用变换、全部 ROI/高度设置和显示设置。弹窗明确说明此范围语义、原已确认范围不额外另存以及已计算结果不保存；用户可取消返回原页面处理。普通 Process/Measure 的既有保存语义不变。

保存服务返回明确的成功/取消/失败状态与所保存快照签名；只有完整文档成功写入且对应当前冻结快照时才能继续打开。保存取消或失败则停止切换。不能根据现有 UI 回调的 `None` 返回值推断成功，也不能要求保存后所有 scope 的 dirty 都为 false；不强行清除另一个 scope 的未保存签名。

分析、数据导出、原生 SEQ/MP4 任务运行或发布、变换草稿编辑、ROI 正在绘制及正在开文件时，打开按钮禁用；不自动取消现有任务或丢弃草稿来换源。结束当前操作后恢复按钮的真实可用状态。

### 11.2 准备、提交与失败

先准备候选 reader/session、同名配置恢复和首帧，成功前保持旧 reader 与画面。文件损坏、SDK 打开失败、空帧或首帧读取失败只释放候选资源，并给出错误；原窗口、旧设置和结果保留。无效侧车沿用现有明确提示并回退默认视图的规则。

提交切换时，保留同一 Figure/原生窗口，安装新页面，返回 Process，更新标题、尺寸、温标、时间线、范围、变换和 ROI；没有有效同名配置时使用新文件默认设置。首次 CLI 的 frame/vmin/vmax 参数不自动套到后来打开的其他文件。

统一 UI dispose 必须幂等，覆盖所有 canvas、widgets、selectors、页面、timer、导出状态、测量面板和视频控制器，不能只 `figure.clear()` 或替换 `session.reader`。部分构建失败时已经注册的候选回调和资源也必须可回收。

切换分为三个明确边界：

1. **拆卸旧 UI**：记录当前页面/子视图和帧位置，停 timer、断开输入并释放旧 widgets/axes；保留旧 reader、ROI/标定设置、dirty 签名及结果表。不能复用会清空测量状态的最终关闭回调。
2. **安装并提交候选 UI**：在同一 Figure 中安装新页面并完成首次绘制。成功后新会话成为当前会话，才最终关闭旧 reader/SQLite、清理旧结果目录。
3. **失败回退**：安装/首次绘制失败时只销毁候选资源，以仍完整持有的旧会话重建旧 UI，恢复原页面、帧位置、设置和结果。

窗口控制器集中拥有当前 reader/session/UI 和正在准备的候选资源；最终关闭及 `launch_viewer` 的清理始终针对届时的当前会话，而不是启动时捕获的第一个 UI。不能在切换前提前退出旧 reader 的所有权上下文。

旧文件 ROI、标定、缓存、全段结果和导出确认状态不迁移到新文件。成功打开同名配置只恢复新文件自己的合法设置。反复切换不叠加回调，不遗留句柄或后台任务。原有 CLI `view`、EXE 双击选文件与单文件拖入入口保留。

## 12. 实现边界与模块职责

| 边界 | 职责与复用 |
| --- | --- |
| 高度设置/数学模块 | 纯数据验证、行坐标映射、标定、分区与加权归约；复用现有 `measurement_stats.profile` 的有限值规则 |
| 高度结果存储/任务 | 独立 reader 逐帧计算、磁盘表完整性、查询与后台取消；复用现有 measurement_job/store 模式 |
| 高度视图/控制器 | ROI 设置、复选框、当前帧/分区绘图及状态，不承担磁盘导出和 SDK 所有权 |
| 高度 CSV 导出 | 冻结快照、分块生成/验证、进度与安全发布；复用文件保护和目标快照 |
| selection / export_bundle | v4 兼容、高度设置与已知来源链、子 SEQ 配套配置 |
| 窗口控制器 / UI dispose | 当前会话所有权、新文件准备、切换提交/回退及旧资源释放 |
| viewer_theme / 导出 UI | 根据导出状态切换按钮 role，保持现有主题与实际鼠标交互 |

避免把新增业务全部堆进现有 viewer.py 闭包。旧接口能用小适配器维持时不无关重构；同一窗口 dispose 是切源所必需的改动。

## 13. 验证与验收

实现阶段按行为验证，不以本设计文档作为通过证据。

1. **数学**：已知梯度/常值矩阵、两种热端、半像素行中心、独立标定、H=1/2/3、NaN/Inf/整行无效；不等有效数的行证明分区采用像素加权；验证 A−B 符号与 ROI 极差区别。
2. **设置**：比例/标定非有限与非正输入、非法切点、每区至少一行、ROI 改高后的比例和分区规则、方向/标定/区间变化不触发 SDK 重读；旧派生结果不能误导出。
3. **存储与 CSV**：全行数、唯一性、源帧/局部帧、统一 t0、排序、未勾选分区仍有完整数据、导出范围不依赖图形勾选、无效行保留、mm 空值、精度及自带追溯字段。分块验证，不用完整载入 CSV 才核验。
4. **后台与保护**：取消、读取失败、磁盘不足、源变化、目标外部变化、覆盖、临时文件清理、UI 响应及内存有界。坏/缺来源映射不伪造原录像索引。
5. **配置**：v1/v2/v3 迁移、v4 往返、严格键/引用校验、高度设置 dirty、子 SEQ 来源偏移累计与未知来源状态、保存取消/失败不继续换源。
6. **GUI**：实际鼠标操作分区复选框、方向、标定、切页和滑块；导出确认真实蓝色与失效恢复；隐藏控件不争抢输入；100/150/200 DPI 与最小支持窗口下检查排版。
7. **切源**：A→B→A、同文件/别名、取消、坏文件、首帧失败、新 UI 安装失败回退、忙碌拒绝、未保存三种选择、timer/回调计数与 reader/SQLite 释放。
8. **最小真实 SEQ**：从项目 raw 中最小文件只读验证高度分析、完整与分区 CSV、标定往返、子 SEQ 来源映射和切源；以导出的最小子 SEQ 作为第二个文件，避免自动加载大 SEQ。测试前后核对全部原始文件的大小与 mtime。
9. **便携包**：实际冻结程序回归高度计算/CSV/切源，使用项目内独立目录；没有独立干净电脑验证时明确标注。较大正式数据性能和原生交互由用户补充验收。
