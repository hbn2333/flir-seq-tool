# 浅色界面轻量美化

用户已选择浅色并要求简单调整，本轮按已批准方向实施，不增加交互设置或更换 GUI 框架。

## 外观与边界

沿用 Matplotlib 控件及 Process / Measure 工作流，使用浅灰页面、白色分区、深灰文字与蓝色选中态。统一按钮、输入框、滑块、边框和字体，突出确认/应用/计算等主要操作。普通操作为白色，忙状态不可用控件使用淡灰色。ROI 名称与框线继续使用其自身颜色。

在现有布局后方添加不接收输入的背景分区，Process 区分图像、控件、状态，Measure 区分图像、ROI、分析图、输出/状态。编辑模式只切换背景分区可见性；沿用全部控件位置，仅将 Measure 帧号输入框宽度从 0.05 调为 0.04，避免跨过分区边界。保留鼠标事件、窗口缩放警告和 F1 详情功能。

主题只作用于当前交互 Figure，不修改全局 rcParams、图像配色、温度数据、PNG 报告或 MP4 渲染。浅色分析图外观也只在 Measure 当前窗口应用，不修改共享导出绘图函数。

## 实施步骤

1. 新建 `viewer_theme.py`，集中定义配色、控件样式、页签选中态、背景分区和界面字体；添加样式隔离/生命周期回归。
2. 在 viewer、transform_editor、measurement_panel 的构造与已有刷新节点调用样式函数，选中/禁用状态跟随原业务状态。
3. 渲染 Process、旋转裁剪和 Measure 的实际界面截图检查外观；运行控件/页面/布局及导出隔离回归；记录结果并提交分支，等待用户查看。此次不自动合并或推送。

## 验证标准

控件启用/禁用、隐藏控件鼠标回归、页面切换和主题刷新仍按现有逻辑工作；图像配色和固定温标不变；全局 Matplotlib 默认样式不变；独立报告与 MP4 保持原样。检查最小窗口与高 DPI 的边界，避免增加文字遮挡。
