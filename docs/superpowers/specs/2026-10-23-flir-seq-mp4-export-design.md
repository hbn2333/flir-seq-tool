# MP4 展示视频导出设计

## 已确认的需求

- Process 添加 Export MP4，导出已 Confirm range 的工作范围，而非 Selected range 候选区间。
- 使用已 Apply 的旋转裁剪、当前配色和固定温标；不显示 ROI、软件按钮或测量曲线。
- 1920×1080 画布，热图保持比例，右侧固定摄氏温度色条，文字为相对时间与播放倍率。
- 默认 1×，支持 2×、5×、10×。相对时间以工作范围首帧为零，不代表实验加热开始。
- 操作顺序为倍率设置、另存为、摘要确认、后台导出；有进度和取消，失败不留下正式半成品。
- MP4 仅用于展示，不替代 SEQ 或温度 CSV，不改变原始文件。

## 方案选择

采用固定帧率视频加源时间戳映射。相比“每张源图固定对应一帧”，该方案保持实验时间关系；相比可变帧率输出，第一版使用统一的输出时间网格，便于测试、播放器检查和倍速处理。

输出采用 H.264、yuv420p、30 fps，无音轨。码率控制初值 CRF 18、编码预设 medium，启动前确认 libx264 可用，不自动替换为其他编码器或安装软件。这些参数作为第一版内部默认值，不增加用户设置项。

## 时间规则

先只读扫描所选范围的时间戳，得到相对时间序列。多帧范围要求时间严格递增；重复、倒退或无效时间戳应明确报错，不猜测帧率修复。

令源首末时间差为 D 秒，倍率为 s，输出帧率 f=30。对 D>0，输出帧数为 `ceil(D*f/s)+1`；第 k 帧查询时刻为 `min(k*s/f,D)`。选取不晚于查询时刻的最近源帧，最后一帧明确使用源末帧。只选帧或重复帧，不对相邻帧温度作时间插值。

画面 t 显示实际选中源帧相对时间（两位小数），不是伪造的均匀采样时间。实验采样有间隔时画面保持上一帧，t 也保持；倍速可能跳过部分源帧。摘要说明展示视频不保证保留每张源图。

包含末帧的显示会使视频时长比 D/s 多不到两个输出帧周期。摘要同时给出实验持续时间和精确预计视频时长 N/f。单帧范围单独导出 1 秒静止视频，t=0，摘要明确说明。

## 画面与交互

画布使用白色背景；热图等比例放在主要区域，色条和时间留在图像外，避免遮挡样品。不含绝对日期、源路径或帧号。不为填满画布裁掉图像；空间插值使用现有温度变换，渲染放大不再次改变温度矩阵。

倍率设置用简单原生单选框，关闭即取消；不在主界面长期增加倍率输入控件。另存为仅接受 .mp4，缺少后缀自动补齐，默认目录沿用 clips，建议名称为源文件主名加确认范围。第一版不新增跨会话路径或倍率记忆。

选择完成后冻结源身份、已确认范围、变换、配色、温标、倍率及目标快照。只读预检阶段扫描时间戳并可取消；就绪后在主线程显示摘要确认框，列出完整路径、源帧范围、D、s、N/f、1080p/30 fps、温标及覆盖状态。取消摘要不写成品；确认后启动编码。

预检及编码期间禁止切页、改范围、改变换和启动其他计算/导出。复用主窗口 Cancel export，并显示阶段：检查时间、生成视频、验证视频、发布。最终替换阶段不可取消，状态须明确。

## 模块与资源生命周期

- video_timeline.py：纯时间戳验证、帧数和源帧映射，可独立单测。
- video_export.py：冻结请求、编码器发现、后台任务、进度、取消、验证与发布。
- video_renderer.py：固定尺寸的热图、色条和文字渲染，不访问交互窗口。
- selection_dialogs.py：倍率选择、MP4 另存为和摘要确认，均由 GUI 主线程调用。
- viewer.py / viewer_pages.py / viewer_layout.py：按钮与任务状态接入；不将编码逻辑堆入 Viewer。

后台任务独占自己的 SDK reader，逐帧读取；允许存储 O(N) 时间戳/索引，但只保留有限数量的温度矩阵和 RGB 帧，不保存整个视频的像素数组。渲染应与 GUI 的 Matplotlib 状态隔离，优先使用独立工作进程；进程间仅传请求、进度、错误和取消信号。

FFmpeg 以参数数组和 shell=False 启动，不拼接用户路径为 shell 命令。Windows 子进程隐藏控制台。通过管道流式输入 RGB，持续消费错误输出并保留有上限的诊断尾部。取消必须能终止编码器并回收 reader、管道和工作进程；不能让阻塞的管道写入无限期拖住关闭。

本机检查发现 PATH 上的 FFmpeg 4.3.1 支持 libx264，未发现 ffprobe。第一版不依赖 ffprobe：最终验证使用 FFmpeg 完整解码临时视频，检查退出码、1920×1080 尺寸和实际解码帧数是否等于 N；损坏、缺帧或解码失败均禁止发布。验证阶段也支持取消。缺少 FFmpeg 或 libx264 时先报错，不先生成输出。

## 文件安全

只操作用户选择的输出目标及本任务独占的临时文件。沿用源文件、raw、别名与目标快照保护；禁止将源文件作为目标，也禁止写入受保护原始目录。当前固定 raw 路径的可移植性限制不在本次扩大修复。

同目录创建唯一命名 .partial.mp4，写完关闭编码器后验证，复核源文件身份和目标快照，再原子替换正式 MP4。既有目标在确认后被修改则失败，不能重新抓取快照后静默覆盖。取消或失败只删除本任务临时文件，既有 MP4 保持不变；删除失败要报告残留路径。

MP4 不生成 selection 配套文件，不修改现有 schema。源大小及 mtime 在任务前后核验；不承诺检测所有同大小同 mtime 的外部改写，用户应避免同时修改源文件。

## 验证与交付

单测覆盖四种倍率、不规则采样、首末帧、单帧、时间异常、冻结输入、取消、编码器缺失、编码失败、解码失败、覆盖竞争、路径别名与资源回收。

集成测试用最小真实 SEQ 的少量帧，导出 1× 和加速视频，验证尺寸、解码帧数、时长容差、末帧及固定温标；检查原始文件大小和 mtime 不变。真实数据不覆盖原文件或已有实验产物。UI 测试覆盖对话框取消、摘要确认、忙状态、关闭以及隐藏控件鼠标回归。

生成代表性视频帧检查宽高比、色条、文字与留白；用户最终用播放器检查视频及原生窗口交互。更新 README 和 CHANGELOG，完整回归后提交功能分支，不自动合并或推送。
