# FLIR SEQ：Process / Measure 双页面与矩形测温设计

日期：2026-10-22

状态：设计草案，等待用户审核；不是实现完成记录。

代码基线：`0031a0f`，已合并并推送至 `main`。

唯一工作目录：`D:\carbonfoam\infrared`。

## 1. 目标与已确认范围

目标是对单个 SEQ 做可追溯的初步测量与可视化，不替用户进行实验解释或跨实验比较。使用同一个窗口，顶部提供 `Process` 和 `Measure` 两个工作页面。

用户已逐项认可：

- `Process` 保留现有逐帧浏览、范围选择、旋转裁剪、保存加载和子 SEQ 导出。
- `Measure` 使用已经 `Confirm range` 确认的工作范围，以及已经 `Apply` 的旋转裁剪。
- 矩形 ROI 在 `Measure` 中创建，支持多个区域，并选择其中几个叠加曲线。
- 当前帧统计随切帧和 ROI 调整更新；整段曲线通过 `Calculate` 手动计算，支持进度和取消。
- 当前帧提供均温、最高温、最低温、温差、标准差、温度直方图和水平/竖直平均温度剖面。
- 当前帧详细分析聚焦一个选中的 ROI；帧序列曲线支持多个 ROI。
- 不设置实验加热零点，不做热电偶同步，不做跨实验对比。

后文的具体布局、计算口径、保存格式、输出方式和任务锁定规则是本草案的推荐细化，需随文档一起审核，不能视为已经实施或逐条获批。

## 2. 方案选择与边界

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 同一窗口、共享会话、顶部双页面 | 不需重复导入，预处理结果直接测量，操作连续 | 必须严格管理可见控件和失效状态 | 推荐，符合用户选择 |
| 测量使用独立窗口 | 两个窗口可同时显示 | 窗口和数据状态容易混淆 | 本轮不采用 |
| 导出子文件后进入独立分析器 | 输入边界清楚 | 每次调整都增加导出、打开步骤 | 本轮不采用 |

继续使用现有 Matplotlib 查看器。顶部导航采用具有选中状态的页面按钮，在同一 Figure 内切换页面；这是双页面交互，不要求迁移到 Web、Qt 或另一个应用框架。保留现有 CLI 启动方式。

本轮不包括：单点/自由多边形测温、自动跟踪、孔隙分割、毫米标定、自动识别热端、多个时刻剖面叠加、跨文件对比、拟合导热率、相变识别、储能计算、热电偶同步、视频导出或发表级排版。

空间剖面首先使用裁剪后像素坐标，水平向右、竖直向下。界面不把图像方向自动解释成实验传热方向。

## 3. 页面与布局

### 3.1 公共框架

- 顶部：`Process | Measure`，始终显示当前选中页。
- 数据标题：源文件简称、已确认源帧范围、局部帧/源帧、当前帧时间戳。
- 底部：状态、错误和任务进度；长信息沿用 F1 全文机制。
- 两页共享当前帧和已应用视图；切换页面不清除区域、结果或未保存状态。
- `Process` 中的候选范围不会改变 `Measure` 的计算范围。进入 Measure 时若有未确认候选范围，显示“使用已确认范围；候选范围未应用”。
- 尚未缩小范围时，完整 SEQ 就是已确认工作范围，不要求额外点击 Confirm。
- 编辑旋转裁剪草稿时，Measure 导航禁用并提示先 Apply/Cancel，不自动应用或丢弃草稿。

### 3.2 Process

保留现有功能和候选范围保存/子 SEQ 导出语义，仅为顶部导航和公共状态区调整布局。不要在这一页加入 ROI 编辑、统计图或分析结果按钮。

### 3.3 Measure

文字布局示意，不规定最终像素尺寸：

```text
┌────────────────────────────────────────────────────────────┐
│ Process | Measure       文件、已确认范围、当前帧             │
├──────────────────────────────────┬─────────────────────────┤
│                                  │ ROI 列表：颜色/名称/勾选 │
│ 热图 + 色标 + 所有 ROI            │ Add / Delete / Rename   │
│ 只有选中 ROI 显示编辑手柄         │ x / y / width / height  │
│                                  │ 当前选中区域统计卡片    │
├──────────────────────────────────┴─────────────────────────┤
│ Current frame 滑块 + 帧号输入                             │
├────────────────────────────────────────────────────────────┤
│ Current frame analysis | Frame curves                     │
│ 当前帧：Distribution / Profile，Profile 选 Horizontal/Vertical│
│ 序列：上图 Mean/Min/Max；下图 ΔT；Calculate / Cancel        │
├────────────────────────────────────────────────────────────┤
│ Save setup | Export CSV | Export PNG                       │
│ 状态、进度、错误                                          │
└────────────────────────────────────────────────────────────┘
```

- 两个结果视图占用同一片绘图区，不把所有图形同时挤进窗口。
- 右侧统计卡片始终针对当前选中的 ROI，在两个结果视图中都可见。
- 当前帧页面默认显示直方图；剖面提供水平/竖直切换。
- 帧序列页面默认上图为 Mean，下图为 ΔT。上图可切换 Min/Max，所有曲线颜色对应 ROI；不采用温度与温差混在一个纵轴的方式。
- 图例允许缩略名称，完整名称可在列表或详情中读取；不依赖颜色作为唯一标识。
- ROI 列表采用固定可见行数和上一页/下一页，新增区域自动定位到其所在页。不以无限增高列表挤压图像。
- 目标最小布局为 1000×800（100 DPI 下的绘图区）；在 100/150/200 DPI 及放大窗口下验证。更小窗口提示放大，不宣称仍支持完整操作。

### 3.4 输入隔离

每个页面、结果子视图和编辑工具都有显式的显示/启用生命周期。隐藏必须同步停用鼠标、键盘、selector 和定时回调，不能只隐藏 Axes。页面切换前结束当前编辑动作并释放自己持有的输入锁；不得抢占其他工具的鼠标所有权。

Matplotlib 工具栏处于平移/缩放模式时，ROI 创建和拖动暂停；退出工具栏模式后恢复。所有控件只连接一次事件，反复切页不累积回调。

## 4. 矩形 ROI

### 4.1 创建、选择与编辑

- 点击 `Add ROI` 后进入一次性绘制模式，在热图拖出矩形；完成后自动选中，退出绘制模式。Esc 取消。
- 自动名称 `ROI 1、ROI 2…`，有独立稳定 ID 和颜色；允许重命名，名称去除首尾空白后不可为空，在当前会话内唯一。
- 默认勾选参与曲线显示。列表行的“选中”和复选框的“参与曲线显示”是两件不同的事。
- 选择某行后，只激活该 ROI 的编辑手柄；其他矩形仅为可见图形，不各自安装一个活跃 selector。
- 支持拖动整体、调整边角和输入整数 `x、y、width、height`。数字输入提交后更新。
- 删除需要确认，随后选中邻近区域；删除最后一个区域后显示添加引导。
- ROI 可以重叠，各自独立计算；不合并、不去重，也不自动排除孔隙或背景。

### 4.2 坐标契约

沿用旋转裁剪设计：ROI 的唯一权威坐标为裁剪后坐标系 C，左上角像素中心为 `(0,0)`，x 向右、y 向下。

矩形保存整数 `x、y、width、height`，取值为数组切片 `T[y:y+height, x:x+width]`。宽高至少为 1，完整落在已应用图像内。显示边界与像素外边缘一致，例如左边界为 `x-0.5`。

鼠标绘制沿用现有裁剪框的像素边界与容差规则；单击产生的零面积框不创建 ROI。越界或非法数字保留原区域并提示，不静默改变用户输入。不同 ROI 的统计不得使用互相重叠的画图遮罩作为输入，始终读取温度矩阵。

### 4.3 即时反馈

切帧时读取当前帧一次，所有当前帧分析共用该矩阵。拖动时合并高频重绘请求，最多约 10 次/秒；鼠标释放时强制计算最终位置。即时更新只处理当前帧，不触发整段扫描。

## 5. 当前帧分析的数值定义

### 5.1 统计卡片

输入为现有 `FrameTransformer` 输出的摄氏温度矩阵，不从伪彩图或颜色反推温度。纯裁剪/直角旋转保持既有精确重排，其他角度沿用双线性插值，不重复重采样。

对 ROI 中有限温度值组成的集合 $V$，以 float64 累加计算：

- `mean_c`：算术平均。
- `min_c`、`max_c`：有限值最低、最高温度。
- `delta_c = max_c - min_c`：同一帧、同一个 ROI 内的温差，不是整段视频的跨帧极差。
- `std_c`：总体标准差，`ddof=0`；描述区域温度离散程度，不是独立重复样品的误差条或测量不确定度。
- `valid_pixels`、`total_pixels`：有效/总像素数。

NaN 和正负 Inf 不参与统计。存在无效值时显示有效数量和警告；全部无效时五个温度统计为缺失值，卡片显示 `N/A`，不能输出零度。仅一个有效像素时温差与标准差均为 0。

显示默认保留两位小数，不代表仪器精度达到 0.01 °C；CSV 不按显示位数截断。非直角旋转下明确标注“基于重采样温度”。

### 5.2 温度直方图

针对选中 ROI 的有限像素。横轴为温度 °C，纵轴为每个箱内的有效像素占比，不是概率密度，也不是物理面积比例。

默认 32 个等宽箱，范围覆盖当前 ROI 的有限值最小值至最大值；常温常值矩阵用该温度 ±0.5 °C 的非零范围。全部无效时显示空图及原因。

随帧自动更新箱范围，并在图上注明“当前帧自动范围”；不得将不同帧相同箱编号解释为相同温区。CSV 明确输出每个箱的左右温度边界、像素数、比例及总有效数。第一版不提供固定箱边界的额外编辑界面。

### 5.3 水平/竖直平均剖面

- Horizontal：ROI 内每列有限值平均，横轴为裁剪后 x 像素中心坐标。
- Vertical：ROI 内每行有限值平均，横轴为裁剪后 y 像素中心坐标，标注“向下增加”。

每个位置独立统计有效像素数，空列/空行为缺失值，曲线在此断开。不做平滑、插补或异常温度阈值剔除。对应方向只有一个像素时显示一个数据点。

这是指定矩形内的横向平均，不是无宽度的单像素测温线，也不自动等同于样品轴向或内部温度场。

## 6. 帧序列统计

### 6.1 输入和触发

点击 `Calculate` 时冻结：源文件身份、已确认的源帧起止（两端包含）、已应用变换、全部 ROI 的 ID 和几何坐标、统计规则版本。

一次扫描计算全部已创建 ROI，而不仅是勾选显示的区域。这样只切换曲线复选框、名称、颜色或 Mean/Min/Max 时无需重新读完整 SEQ。没有 ROI 时禁止计算。

每帧读取并变换一次，复用于所有 ROI。保存该帧的五个统计量及有效数，不保存整段温度矩阵、逐帧直方图或逐帧空间剖面。

### 6.2 曲线

- 横轴固定为已确认工作范围内从 0 开始的局部帧号。
- 上图由 Mean/Min/Max 单选控制，下图固定显示 ΔT，各自叠加勾选的 ROI。
- 两图显示当前帧竖线；单帧范围显示标记点，不要求至少两个点。
- 所有 ROI 都未勾选时显示选择提示，不重新计算。
- CSV 保留真实绝对时间戳、源帧号、局部帧号和相对工作范围起点的秒数。该秒数仅为浏览区间时间，不命名为实验加热时间。
- 无效帧内的统计缺失表现为曲线断点，不能连成零温度曲线。

### 6.3 结果状态与失效

结果状态为：未计算、计算中、已完成、需重算、已取消或失败。只允许完整且匹配当前输入的结果用于正常曲线展示和导出。

| 操作 | ROI | 全段结果 |
| --- | --- | --- |
| 切帧、切页面、切结果视图 | 保留 | 保留 |
| 改色图/显示温标、ROI 名称/颜色/显示勾选 | 保留 | 保留数值，只更新显示/导出描述 |
| 拖动尚未 Confirm 的候选时间范围 | 保留 | 不变，Measure 仍用原工作范围 |
| Confirm 新范围或 Reset full，实际范围改变 | 保留 | 失效；本版不自动裁取旧结果 |
| 新增、删除、改变 ROI 几何 | 更新 | 全段结果标记需重算 |
| Apply 实际不同的变换 | 提示确认后清除 | 清除 |
| Apply 与当前相同的变换、Cancel 草稿 | 保留 | 保留 |
| 成功加载配置 | 原子替换为配置中的 ROI | 清除，重新计算 |

变换变更提示明确列出将清除的 ROI 数量；用户拒绝时保持编辑草稿和旧标注，不应用新变换。

失效旧结果不继续伪装成当前结果：绘图区显示需重算提示并禁止导出该曲线。重新计算时旧结果可暂存；取消/失败后仅当它的输入签名仍与当前状态完全一致，才恢复为有效结果，否则保持需重算。

## 7. 后台计算与资源

采用一个后台分析任务，不将线程直接接入 Matplotlib。后台只产生进度、结果和错误，主线程通过现有 timer 风格轮询更新 UI。

- 后台线程自行创建、使用、关闭独立只读 `ScienceFileReader`，不跨线程共享现有 ImagerFile 或可变帧缓存。
- 为避免同一 SDK 的并发读取未经验证，计算期间暂停切帧、ROI 编辑、配置加载保存、预处理修改、页面导航及所有导出；窗口保持响应，Cancel 可用，已有画面不消失。
- 分析任务与原生导出互斥。后台结束并释放读取器后恢复控件，单帧控件等原有禁用条件不能被统一启用覆盖。
- 每帧之间检查取消，进度为已完成帧/总帧。SDK 当前帧调用无法保证立即中断，明确显示“正在取消”。
- 读取任一帧失败时整体任务失败并报告源帧号，不把不完整序列作为成功结果发布。
- 源身份在开始与结束核验；检测到变化则拒绝发布结果。
- 关闭时请求取消并等待后台通过正常路径释放资源；不能遗留运行中的回调或提前关闭仍被使用的句柄。

内存约束：帧矩阵只保留当前帧及既有有界缓存。统计表大小为 $O(NR)$，不是常量；设计采用临时磁盘结果存储和分块访问，不能因曲线数据再次无界占用内存。

长曲线绘图可在局部帧轴上按至多 2000 个桶提取每桶有限值最小/最大值及端点，按帧顺序绘制，并保留无效间断。图上注明抽稀显示，CSV 始终导出完整逐帧结果。当前帧卡片仍直接根据该帧矩阵计算，不读取抽稀图形。

临时结果用独立、工具拥有的临时目录；失败、取消及关闭时关闭存储后清理，仅删除自己创建的文件。磁盘空间不足应保留旧有效结果并报错，不留下看似完整的新结果。

## 8. 保存、加载与导出

### 8.1 测量设置

推荐将 selection 升级到 schema v3，在原有 source/selection/display/transform 之外加入 `measurement`：

- `coordinate_space`：固定 `cropped_pixel`。
- `rois`：按显示顺序保存 ID、名称、整数 x/y/width/height、颜色和曲线显示勾选。
- `active_roi_id`：当前选中项，可为空；非空必须引用现有 ROI。
- `result_view`：当前帧或帧序列。
- `frame_view`：分布或剖面，及水平/竖直方向。
- `curve_metric`：mean/min/max。

几何和数值结果分离：JSON 保存可重算的设置，不保存完整曲线。重新打开恢复 ROI 和当前帧分析，全段曲线显示“未计算”。严格校验字段、ID 唯一性、名称、有限数值、坐标范围和枚举；禁止把畸形配置静默修正为其他区域。

读取兼容 v1/v2，将 measurement 视为空；保存写 v3，不自动改写读入的旧文件。旧版工具不承诺能读取 v3。加载必须完成全部校验后一起替换会话；无效配置或取消确认不改变现有状态。

### 8.2 两个页面的保存范围

避免悄悄改变已有 Process 语义：

- Process 的 `Save selection` 仍保存候选范围，同时保存当前已应用变换和 ROI 设置；重新加载后，该保存范围成为工作范围。
- Measure 的 `Save setup` 使用同类 `.selection.json` 文件，但明确保存当前已确认工作范围及 ROI 设置，不采用 Process 未确认候选范围。
- 保存对话框和摘要明确显示所存范围。Measure 保存后，如果 Process 还有不同的未确认候选范围，不能把整个会话错误标为已全部保存；需分别维护预处理候选状态和测量设置的脏状态。
- 加载入口仍放在 Process，避免双份加载逻辑；Measure 可以保存，不新增另一个导入系统。

沿用已有原子保存、单份 .bak、覆盖确认和外部目标变化检测。ROI 的编辑也参与未保存更改保护。

### 8.3 子 SEQ 配套配置

Process 原生导出仍按其候选范围工作。配套 v3 selection 携带冻结的 ROI 设置和变换，绑定新子文件身份；由于原生导出不改变像素几何，ROI 坐标不变，子文件帧号仍从 0 重编。

不复制父文件的曲线结果，不宣称 ROI 或变换已写进 SEQ 像素。重新打开配套子文件后可恢复 ROI，并按子文件重新计算。

### 8.4 分析结果输出

Measure 提供 `Export CSV` 和 `Export PNG`，均弹出文件选择框。默认建议输出到 `analysis`，实现时将其加入 .gitignore；本设计阶段不创建该目录。

- 当前帧 Distribution：CSV 导出直方图各箱及当前 ROI 统计。
- 当前帧 Profile：CSV 导出当前方向每个像素位置的均温、有效数及 ROI 总体统计。
- Frame curves：CSV 导出勾选 ROI 的完整逐帧统计，包含 mean/min/max/delta/std；不只导出当前上图所选指标。
- PNG 输出当前结果图，并加入对应热图/ROI 定位和必要标题，不截取按钮、输入框等界面控件。

CSV 使用 UTF-8 BOM、标准表头和长表格式。每行包含源文件身份的可序列化字段、已确认源帧范围、已应用 transform 的 JSON 表达、算法版本、ROI ID/名称/几何和相应帧信息；允许重复元数据以保持单个 CSV 自包含，不依赖额外侧车文件。表头按输出类型固定，不能随勾选顺序变化。

导出开始时冻结当前帧、结果类型、显示选项和 ROI 设置，完成前禁用编辑及重复导出，避免图片与数值来自不同状态。绝对时间戳保留 SDK 提供的时区信息；无时区的时间不擅自标为 UTC。PNG 标明当前帧或曲线源帧范围、ROI 名称和数值单位；CSV 另保留结果格式版本，便于后续解析。

统计缺失输出空字段并携带有效数量/状态，不写零或 JSON 非标准 NaN。对名称等用户文本采取表格公式注入防护，同时用标准 CSV 引号处理逗号、换行与引号。

每次只输出一个独立文件。沿用源/raw 路径保护、目标快照和明确覆盖确认，以同目录临时文件写完校验后替换；PNG 校验可解码及尺寸，CSV 校验表头和预期行数。取消或失败不留下正式半成品，也不覆盖确认后被外部更改的目标。

## 9. 代码职责划分建议

现有 viewer.py 已集中较多事件逻辑，不继续把测量算法和后台任务塞入同一函数。

| 模块职责 | 输入/输出 | 边界 |
| --- | --- | --- |
| ROI 与测量会话模型 | 合法矩形、选中状态、输入签名、结果状态 | 不依赖 Matplotlib 或 FileSDK |
| 当前帧统计函数 | 温度数组与矩形 → 统计/直方图/剖面 | 纯数值，可用合成数组验证 |
| 帧序列计算任务 | 冻结请求、reader 工厂 → 进度/结果存储 | 不操作 UI，不共享可变 session |
| 结果存储与输出 | 完整统计表、设置 → 分块读取/CSV/PNG 输出 | 有界内存、明确文件所有权 |
| Measure 页面控制器 | 会话、当前帧 → ROI 工具、数值卡片和图形 | 管理页面事件启停，不直接承担文件解析 |
| 顶部页面协调器 | Process/Measure 导航与任务状态 | 只协调共享状态和互斥规则 |
| selection v3 适配 | 设置 ↔ 已校验文档 | 复用已有身份及写保护，不存曲线数组 |

复用 FrameTransformer、TimelineState、SelectionDialogs、file_safety 和原始读取接口。页面拆分只做本功能所需的职责隔离，不顺带重写底层 SDK、原生导出事务或整个 UI 框架。

## 10. 验证与验收

### 10.1 数值测试

- 常值、线性梯度、已知离散矩阵，验证 mean/min/max/delta/std 和 ddof=0。
- 单像素、单行、单列、单帧、全部无效和混合 NaN/Inf。
- 重叠 ROI、边界 ROI、横竖平均方向和有效像素分母。
- 直方图箱边界、最右端归属、常值扩展区间及比例之和。
- 0°、90° 和非直角变换后的 ROI 结果与直接数组切片计算一致。
- 全段统计的每帧结果与当前帧统计一致；显示小数位不改变输出精度。

### 10.2 状态、配置和任务测试

- 未确认候选范围不改变 Measure，Confirm/Reset 才触发结果失效。
- 多 ROI 编辑、勾选、改名、删除对结果签名的影响符合第 6.3 节。
- 变换变更确认/取消、相同变换 Apply、加载失败均不误清状态。
- v1/v2 兼容、v3 往返、源身份不匹配、非法 ROI、取消保存和覆盖保护。
- Process/Measure 两种保存范围、脏状态，以及子 SEQ 配套 ROI 恢复。
- 后台异常、取消、关闭、磁盘失败、源文件变化和结果发布的时序。
- 临时结果存储和抽稀读取有明确边界；完整 CSV 不受抽稀影响。

### 10.3 真实输入和布局测试

使用实际 MouseEvent/KeyEvent 模拟导航、ROI 创建拖动、滑块和文本框交互，不仅调用 set_val。覆盖反复 Process/Measure、Current frame/Frame curves、Distribution/Profile 切换，确认无隐藏控件抢鼠标、无重复回调。

在目标窗口尺寸及 100/150/200 DPI 渲染，检查标签、色标、列表、卡片、图例和状态区不重叠；测试工具栏平移/缩放与 ROI selector 互斥。

真实 SEQ 自动测试仅使用最小文件的少量帧：确认范围、应用变换、建立至少两个 ROI、核对逐帧统计与剖面、保存加载、导出 CSV/PNG、子文件恢复 ROI。测试前后 stat 三份 raw 的文件列表、大小与 mtime；不覆盖、不修改、不重命名原文件。大文件浏览和长任务表现由用户手动验收。

### 10.4 用户验收路径

1. 用原 CLI 打开最小 SEQ，确认范围并 Apply 旋转裁剪。
2. 点击 Measure，图像和工作范围与已应用状态一致。
3. 创建三个 ROI，选中其中一个，切帧观察卡片、直方图和两个方向剖面。
4. Calculate 后勾选不同 ROI，切换 Mean/Min/Max，查看 ΔT 和当前帧位置。
5. 调整 ROI 后显示需重算；切页、切帧、改名和勾选不会误触发全段扫描。
6. 保存设置、重新加载并恢复区域；曲线要求重新计算。
7. 导出完整数值 CSV 和当前结果 PNG，与界面数值及已知帧对应。
8. 返回 Process 调整实际变换，检查清除标注的确认；取消应保留旧状态。
9. 用户自行验证大文件任务的响应、取消和退出。
