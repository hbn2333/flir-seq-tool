## Process / Measure 验证边界

- 自动测试覆盖 ROI 有限值统计、32 箱自动分布、双向像素剖面、selection v3/旧版兼容、双保存范围、冻结输入与后台 SQLite、取消/失败/关闭、失效、完整 CSV 和无 GUI PNG。
- Measure 四种子视图以真实 renderer 检查 100/150/200 DPI × 1000×800/1600×1000 逻辑尺寸；稳定渲染图位于本地忽略目录 `picture/process-measure-review-1792613669127`。这些 Agg 事件/渲染验证不替代 Windows 原生窗口。
- 标准差是总体定义 `ddof=0`；无有限像素为缺失，单像素为零温差/标准差。任意非直角旋转后的 ROI 统计基于插值温度。剖面距离只有像素单位；直方图箱范围逐帧自动变化，不适合直接对比固定箱。
- 曲线按桶保留首/极小/极大/末代表值，缺失断线；显示抽稀不改变完整 CSV。结果临时缓存不写入配置，重新加载需重新 Calculate。未引入加热零点、毫米标定、热电偶同步或实验物理校准。
- 最终完整回归的实际数字和三份 raw 元数据对照见 [执行记录](superpowers/plans/2026-10-22-flir-seq-process-measure-execution.md)，不以计划预期替代运行结果。大文件只检查元数据，没有读温度或声称通过性能验收。
